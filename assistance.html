Aide Budget Orion

Bien démarrer

Ouvre Plus → Bien démarrer. Renseigne le solde du premier jour du mois, puis les revenus et dépenses. Marque les opérations reçues ou réglées uniquement lorsqu’elles ont réellement eu lieu.

Comprendre les montants

Solde du mois = solde de départ + revenus reçus − dépenses réglées − épargne transférée hors du compte suivi. La projection inclut aussi les revenus attendus et les dépenses encore dues. Elle ne représente pas une connexion à ta banque.

Protéger ton budget

Plus → Exporter toutes mes données permet de créer une sauvegarde JSON. Conserve une copie externe, notamment avant toute mise à jour ou tout changement de téléphone. Une mise à jour de code ne déplace pas les données du navigateur vers l’application native : utilise export puis import.

Une erreur d’enregistrement apparaît

La modification n’est pas confirmée. Exporte tes données, conserve le formulaire affiché et réessaie. N’efface pas les données du navigateur pour corriger un problème.

Une ancienne sauvegarde est refusée

Conserve le fichier original. L’import bloque les structures incompatibles avant de remplacer les données. Ne modifie pas le fichier au hasard pour contourner ce contrôle.

Rappels

Sur le web, les alertes sont vérifiées à l’ouverture ou au retour dans l’application. La version mobile préparée programme des rappels locaux avec permission, selon les réglages du téléphone. Un rappel n’effectue aucun paiement.

Signaler un problème

Note l’écran concerné, les étapes et le message exact. Évite de transmettre un export contenant des données personnelles. L’adresse d’assistance de l’éditeur sera ajoutée avant publication sur les boutiques.
