# Mise en ligne GitHub Pages

1. Décompresser le ZIP.
2. Dans le dossier `Budget-Orion-GitHub`, sélectionner **son contenu** (pas le dossier lui-même).
3. GitHub > dépôt `Budget-mensuel-` > **Add file > Upload files**.
4. Glisser tous les fichiers/dossiers.
5. Commit changes.
6. Attendre 1 à 2 minutes puis recharger l'application.

Les données utilisateur sont dans `localStorage` du navigateur : remplacer les fichiers du dépôt ne les efface pas.

Fichiers actifs principaux :
- `index.html`
- `css/*.css`
- `js/app.js`
- `js/brands.js`
- `manifest.webmanifest`
- `sw.js`
- `icons/*`
