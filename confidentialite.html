Confidentialité et données

Budget Orion 7.3 · mise à jour le 4 octobre 2026

Ce que contient ton budget

Les revenus, dépenses, catégories, objectifs et événements que tu saisis restent sur ton appareil. Cette version ne connecte aucun compte bancaire, ne contient aucune publicité et ne transmet pas ton budget à un serveur Orion.

Stockage et sauvegardes

Sur le web, les données sont conservées dans le navigateur. La version mobile préparée ajoute une copie locale dans les préférences de l’application. Ce stockage n’est pas un coffre chiffré et ne constitue pas une synchronisation entre appareils.

Les fichiers JSON exportés contiennent ton budget en clair. Enregistre-les dans un emplacement privé. Effacer les données du navigateur ou désinstaller l’application peut supprimer le budget local.

Hébergement et permissions

La version web est hébergée sur GitHub Pages, qui reçoit les informations techniques des visites. Les notifications sont facultatives. Dans la version mobile, le partage de fichiers passe par la feuille de partage du téléphone ; son destinataire reçoit seulement le fichier que tu choisis de partager.

Contrôle des données

Tu peux modifier ou supprimer tes opérations dans l’application et exporter une copie depuis Plus. Pour supprimer toutes les données locales, exporte d’abord ce que tu veux conserver, puis utilise les réglages du navigateur ou du système. Cette suppression est définitive pour les copies locales.

Avant publication sur les boutiques

Le nom de l’éditeur et un contact d’assistance doivent encore être renseignés. Cette page décrit la version technique actuelle ; elle devra être complétée et vérifiée lors de la mise en vente.
